현재 판단: 진입 가격 보호 필요 포지션 틱 감시 미흡 작성: 2026-06-07 KST

자동매매 주문 정책 및 포지션 긴급 감시 점검

3% 언더의 빈번한 매매 전략을 기준으로, 현재 자동주문 구조와 보유 포지션 감시 구조를 점검하고 권장 주문 정책과 개선 우선순위를 정리한다.

요약 결론

진입 주문

LIMIT시장가 고정 해제

자동 BUY는 시장가가 아니라 허용 슬리피지 안의 공격적 지정가가 적합하다.

손절 주문

MARKET체결 확실성 우선

손절은 가격보다 탈출이 우선이다. 지정가 손절은 미체결 위험이 크다.

보유 중 감시

TICK캔들 마감 대기 금지

포지션 보유 중 손절/익절은 분봉 마감이 아니라 KIS WS tick 기준으로 평가해야 한다.

핵심 판단: 지금 백엔드 실시간 수집과 캔들 기반 신호 평가는 존재하지만, "포지션을 보유했으니 해당 종목을 최우선으로 붙잡고 매 tick마다 청산 조건을 보는 긴급 감시 모드"는 아직 부족하다.

권장 주문 정책

주문 권장 정책 기본값 근거
진입 BUY 지정가. 단, 소극적 지정가가 아니라 marketable limit: 현재 매도1호가가 허용 상한 안이면 지정가로 진입 허용 슬리피지 0.2~0.3%, 미체결 10~30초 후 취소 시장가 진입은 급등 순간 불리한 체결이 발생하고, 짧은 수익폭 전략의 기대값을 훼손한다.
진입 실패 기본은 취소 후 스킵. 시장가 전환은 옵션이며 기본 OFF 재호가 0~1회, 시장가 전환 OFF 3% 언더 전략에서는 못 사는 리스크보다 나쁜 가격에 사는 리스크가 더 크다.
스탑로스 SELL 시장가 유지. tick 기준 손절선 터치 시 즉시 청산 주문 시장가, 중복 SELL 예약 수량 차감 손절은 체결 확실성이 가격보다 우선이다.
익절 SELL 지정가 또는 공격적 지정가. 미체결 시 재호가 또는 다음 tick 재평가 목표가 지정가, 짧은 timeout 후 재호가 익절은 손절보다 시간 압박이 낮아 가격 보호 여지가 있다.
KIS 스탑지정가 보조 안전장치로만 검토 기본 OFF KIS의 스탑지정가는 stop-market이 아니라 stop-limit 성격이므로 급락 시 체결 보장이 약하다.

BUY 지정가 산정 예시

권장 계산식

maxEntryPrice = signalPrice * (1 + maxEntrySlippagePct / 100)

ask1 <= maxEntryPrice이면 호가단위 보정 후 ask1 또는 ask1 + 1tick 지정가 주문. ask1 > maxEntryPrice이면 진입 스킵.

체결 시도

신호가 100,000원, 허용 0.25%, 매도1호가 100,100원이라면 지정가 100,100~100,200원으로 진입한다.

진입 스킵

신호가 100,000원, 허용 0.25%, 매도1호가 100,500원이라면 너무 비싸므로 매수하지 않는다.

필요한 입력 데이터

  • 시그널 기준가: 현재 구조의 priceAtSignal
  • 현재 호가: KIS H0STASP0 또는 REST/캐시 보조
  • 호가단위 보정 함수
  • 미체결 취소 timeout
  • 부분체결 처리 정책

개선 우선순위

1자동 BUY 지정가 전환

자동 주문 생성부의 MARKET 고정을 해제하고, 전략/리스크 설정에 따라 LIMIT와 limitPrice를 계산한다.

  • maxEntrySlippagePct 추가
  • 호가단위 보정
  • 미체결 취소 timeout
  • 시장가 전환 옵션은 기본 OFF

2POSITION 실시간 구독 owner

BUY 체결 후 포지션이 생기면 해당 종목을 사용자 화면이나 스크리너 TTL과 무관하게 계속 구독한다.

  • RealtimeDemandOwner.POSITION 추가
  • watchlist보다 높은 우선순위 부여
  • 전량 SELL 체결 시 release

3TickPositionRiskWatcher

consumer가 market.tick.v1를 직접 소비해 보유 포지션의 청산 조건을 tick마다 평가한다.

  • 손절 터치 시 시장가 SELL
  • 익절 도달 시 지정가 SELL
  • 중복 SELL 방지 idempotency
  • open SELL 예약 수량 차감

4호가 기반 진입 품질 게이트

스프레드와 호가 잔량이 나쁜 종목은 진입하지 않는다. 짧은 수익폭 전략의 핵심 방어선이다.

  • maxSpreadPct 설정
  • 최우선 매도호가 잔량 확인
  • 호가 구독 slot 부족 시 REST/캐시 fallback 정책

최종 판단

지금 상태 그대로 REAL 빈번매매를 돌리기에는 진입 가격과 포지션 감시가 부족하다. 시장가 BUY 고정은 슬리피지 리스크가 크고, 보유 포지션의 손절/익절이 tick마다 즉시 평가되는 구조가 아니다.
개선 방향은 명확하다. 먼저 자동 BUY를 지정가로 바꾸고, 이어서 POSITION owner와 tick 기반 청산 워처를 추가하면 3% 언더 전략에 필요한 가격 보호와 긴급 탈출 구조를 갖출 수 있다.
