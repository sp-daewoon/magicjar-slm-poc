한 줄 결론

지금 코드는 자동매매 본선이 끊어진 상태는 아니다. 시그널 생성, 리스크 차단, 주문 intent, 주문 라우터, KIS ACK/거절 처리까지 연결되어 있다. 다만 “실전 자동매매를 장시간 켜두고 완전히 안심할 수준”은 아직 아니다. 특히 admin 1분봉 백필이 KIS TPS 초과를 계속 만들 수 있고, 캔들 stale 원인 표시가 부족하다.

자동매매 실제 흐름

1. 캔들 마감WS tick -> 1m DB INSERT -> boundary fanout
2. 전략 평가정규장 게이트, data readiness, DSL 평가
3. Signal 저장DB 저장 후 id가 있을 때만 Kafka publish
4. Risk 평가손실·포지션·빈도·SELL 가능수량 검사
5. Order IntentALLOWED만 order.intent.v1 발행
6. 주문 라우터idempotency, mode, kill switch, 장운영 게이트
7. KIS/DB 반영ACK, REJECTED, PENDING_RECONCILE, 체결 백필

현재 좋게 바뀐 점

주문 안전 게이트

  • 정규장 밖 AUTO 주문은 KIS 전송 전 차단된다.
  • KillSwitch 조회 실패 또는 포트 부재는 fail-closed로 차단된다.
  • REAL 모드에서는 자본·포지션·일손익·오픈주문 context를 못 만들면 리스크 차단된다.
  • SELL 주문은 DB 포지션뿐 아니라 KIS 잔고 조회까지 한 번 더 확인한다.
  • KIS timeout ambiguity는 REJECTED 확정 대신 PENDING_RECONCILE로 보류한다.

시장 데이터 안정성

  • 1분봉 INSERT의 TransactionRequiredException 원인은 TransactionTemplate으로 막혔다.
  • WS 구독 race는 watchlist 등록 후 connect 순서로 완화됐다.
  • 일봉 5분 refresh는 incremental=true로 바뀌어 30년치 재조회 burst가 줄었다.
  • 자동 백필 submit 경로는 동시성 1개, run 간 1.5초 간격, 갭 cap, 회복불가 마킹이 추가됐다.

남은 위험

P0 Admin 1m 백필 Rate Limit

자동 submit 경로는 throttle이 들어갔지만, admin 동기 runBackfill() 경로는 운영자 우회로 설계되어 throttle을 타지 않는다. 실제 로그에서 admin 1m 백필이 연속 실행되며 ConsumerRedisKisRateLimiterAdapter TPS exceeded count가 390까지 증가했다.

주문 직접 발행 문제는 아니지만, KIS 호출 안정성·캔들 보정·리플레이 신뢰도에 직접 영향을 준다.

P0 백필 sanity monotonic 대량 경고

CandleBackfillWorker sanity 실패 monotonic 경고가 수만 줄 발생했다. KIS 응답 정렬 방향 또는 sanity check 기준이 실제 응답과 어긋나 있을 가능성이 있다.

감사 로그상 일부 backfill은 SUCCESS지만 insertedCount=0이다. 성공/미커버/정렬오류를 더 명확히 분리해야 한다.

P1 캔들 stale 원인 가시성 부족

현재는 last candle이 늦다는 결과는 볼 수 있지만, 원인이 WS 미구독·tick 없음·DB insert 실패·KIS 백필 실패·장외 정상 상태 중 무엇인지 사용자 화면에서 바로 알기 어렵다.

P1 리플레이와 라이브 차이

라이브는 정규장 게이트와 REAL risk fail-closed를 탄다. 리플레이가 같은 게이트·예산·포지션 귀속을 완전히 반영하지 않으면 “리플레이에서는 샀는데 라이브는 안 산다”는 의심이 계속 생긴다.

P1 전략별 포지션 귀속

익절/청산 로직은 현재 사용자+종목 포지션을 본다. 동일 종목에 여러 전략이 있을 때 “이 전략이 산 물량인지”까지 분리하려면 strategy ownership 추적이 더 필요하다.

P1 REAL 장시간 canary 부족

단위 테스트와 MOCK 흐름은 확인됐지만, 실전 계좌에서 최소수량·킬스위치·장운영시간·체결백필·거절알림까지 장시간 canary로 검증한 evidence는 아직 부족하다.
